## 📌 About the Project

This project uses **Machine Learning** to predict the success of Nykaa products based on product-related features.

The project covers:

- 📊 Product data analysis
- 🧹 Data preprocessing & cleaning
- 🤖 Machine Learning model building
- 📈 Data visualization
- 🌐 Interactive Streamlit web application
